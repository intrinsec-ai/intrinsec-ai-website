What it catches

One baseline. Every failure mode.

Some failures are attacks and some are just a deep stack breaking. Both are deviations from how your workload normally computes, so one baseline surfaces both, including the failure modes no one has named yet.

Prompt injection

Injected instructions.

Instructions smuggled in through user input, retrieved documents, or tool results compute differently from your workload's normal, including variants no guardrail was trained on.

Jailbreaks & obfuscation

Attacks in disguise.

Encodings, role-play framings, multi-turn coaxing. The text can be dressed up to read innocently; the computation underneath still doesn't match normal.

Data exposure

Information leaving.

Secrets, credentials, and sensitive information surfacing in responses where they never normally appear: the kind of leak a keyword filter can't enumerate.

Rogue tool calls

Actions it shouldn't take.

Requests steering the model toward tools it doesn't normally call (deletion, escalation, outbound access), flagged before the pattern becomes an incident.

Broken tool calls

Nobody attacked you.

A malformed argument, a schema that drifted, a result the model answers around. Nothing threw an error, but the model still computes differently, so it surfaces anyway.

Hallucination & drift

Work it shouldn't do.

Answers invented rather than grounded. A support model giving legal advice. Traffic shifting away from what you deployed for. All of it stands out against the baseline.

Engine-native · Runs in your infra

Built for the serving stack you already run.

Plato rides along with inference, not in front of it.

  • Engines and gateways. Modern inference engines including vLLM and SGLang, and inference gateways. On-prem or cloud.
  • Zero extra cost or latency. Reuses the compute each forward pass already produces, including the KV cache the engine would otherwise discard, so nothing new sits in the request path.
  • Adaptive baseline. Normal is learned from your own workload, not from a generic attack list.
  • Model-agnostic. Swap or upgrade the model you serve (Qwen, GLM, Llama); the security layer carries over.
  • Tagged, not just flagged. Anomalies arrive labeled by domain, task, disposition, and safety flag, in the tools you already use.

Where this goes

DLP tagged data. Plato tags computation.

A prompt is a control input: what matters is not what was said to the model, but how the model fires in response. Plato labels that firing pattern on every KV page (domain, task, disposition, safety flags), off the request path. And because computation lives in a shared, platonic representation space, the labels are not bound to text, to a modality, or to any one model. Hence the name.
